# Mi Agenda Sallenet (PWA)

Rama experimental para migrar LaSalle2.ipynb a una PWA.

- React + Vite.
- Vercel para frontend y función serverless.
- Sin base de datos.
- Sin envío de correo.
- Las notas personales se mantienen porque cada familia consulta su propia cuenta.
- La rama main permanece intacta.

La autenticación contra Sallenet se está migrando desde Selenium a HTTP directo contra Moodle/Sallenet.
